# Support

TelegramAgentBot is community-maintained open-source software. Support is
provided on a best-effort basis through GitHub Issues.

## Usage questions

Before opening an issue:

1. Read the [README](README.md) and [documentation index](docs/README.md).
2. Check [Configuration](docs/configuration.md) and
   [Deployment](docs/deployment.md#troubleshooting).
3. Search existing [issues](https://github.com/Pigbibi/TelegramAgentBot/issues).
4. Run `/health` and collect a short, redacted service log.

If the question remains, open an issue and choose the support option. Include
the operating system, install method, agent CLI, backend, expected workflow,
and relevant configuration with secrets removed.

## Bug reports

Use the bug report form for reproducible project behavior. A support request is
more likely to receive a useful answer when it includes exact steps and a small
log excerpt rather than a full transcript.

The project cannot provide support for private agent prompts, third-party
account billing, Telegram account recovery, or custom infrastructure that
maintainers cannot reproduce.

## Feature requests

Use the feature request form. Explain the user problem, proposed workflow,
alternatives, and security or compatibility impact. Requests are not a promise
of implementation.

## Security

Do not report vulnerabilities or credentials through a normal issue. Follow
[SECURITY.md](SECURITY.md).

## Service expectations

There is no guaranteed response or resolution time. Maintainers may close
requests that lack reproduction details, expose sensitive data, concern an
unsupported third-party service, or fall outside the project's scope.
